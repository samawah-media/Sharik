# أولوية بدء تجربة الفريق — 2026-09-14

## القرار الحالي

**No-Go لدعوة الفريق الآن.** المسار الأقصر هو تجربة داخلية مغلقة ببيانات UAT
صناعية/مصرّح بها وحسابات فردية جاهزة. لا تشمل البداية إنشاء عميل/عقد/باقة من
الصفر، ولا دعوة عميل خارجي، ولا Production. يمكن تحويل القرار إلى Go بعد إغلاق
الحزمة P0 أدناه على Preview غير إنتاجية مرتبطة بالمصدر المراجع نفسه.

- SIL-13، SIL-22 إلى SIL-28، SIL-29 إلى SIL-32، SIL-33، SIL-35 إلى SIL-43،
  SIL-45 إلى SIL-50، SIL-55 إلى SIL-57، SIL-59، SIL-63: تحسينات UX/نسخ/سياق
  عميل يمكن جدولتها بعد بدء التجربة، بشرط عدم ظهور تسريب أو تجاوز صلاحية أو
  تعطيل للمسار الأساسي.

## نطاق التجربة الأولى المقترح

1. Preview غير إنتاجية، عميل UAT واحد، مخرجان أو ثلاثة فقط، ولا بيانات حقيقية
   غير مصرّح بها.
2. حسابات فردية: إدارة، مدير حساب، كاتب مسند، وعضو غير مسند. يؤجل المصمم
   والعميل الخارجي حتى حسم SIL-72 وإعادة تحقق مسار العميل.
3. رحلة: إسناد → مهمة → رفع نسخة → مراجعة داخلية → إرسال لحساب عميل UAT →
   توقف SLA → طلب تعديل → استئناف → اعتماد → ملف نهائي → تسليم.
4. اختبارات منع موازية: عميل/عضو آخر، ملف مباشر، تعليق داخلي، قرار غير مصرح،
   وجلسة عضو معطّل.
5. سجل يومي للعيوب: P0 يوقف التجربة، P1 يصلح خلال يوم العمل، P2 يدخل backlog
   بمالك وموعد ولا يوقف الاستخدام.

## خارج النطاق

Production، دعوات عملاء حقيقيين، إنشاء كامل من الصفر، تحسين كل P2 قبل التعلم
من الفريق، أو اعتبار نجاح المصدر المحلي بديلًا عن DB/CI/Preview/القبول البشري.
