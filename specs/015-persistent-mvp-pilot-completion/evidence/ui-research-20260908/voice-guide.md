# دليل لغة شريك — مقترح للمراجعة

8 سبتمبر 2026. نبرة سعودية خفيفة ومهنية. «شريك» اسم المنتج، وسماوة جهة التشغيل. هذا دليل مقترح، وليس تغييرًا منفذًا للنصوص. لم يراجعه مستخدمون سعوديون بعد.

## القواعد

1. العنوان يخبر المستخدم أين هو، والوصف يقول ما يفعله بعد ذلك. جملة واحدة غالبًا تكفي.
2. نستخدم «تقدر»، «وش»، «اللي تحتاجه» عند الحاجة؛ لا نضع لهجة عامية في كل عنوان أو زر.
3. الأزرار الحساسة ثابتة: «اعتماد النسخة»، «طلب تعديل»، «اعتماد داخلي»، «تسليم نهائي»؛ لا «تمّام» أو «يلا» بدل القرار.
4. نتجنب لوم العميل والموظف. انتظار موافقة العميل ليس تأخّر الفريق.
5. لا نعلن نجاحًا قبل تأكيد الحفظ. عند غموض النتيجة نطلب التحقق من الحالة، لا إعادة القرار عشوائيًا.
6. حالة الفراغ تأتي بعد نجاح التحميل فقط. «غير متاح» ليست صفرًا.
7. نذكر النسخة في قرار العميل؛ الاعتماد ليس تسليمًا أو نشرًا اجتماعيًا.
8. نوجّه الرسالة للدور: تفاصيل العمل للفريق، والنسخة المرسلة والقرار للعميل. لا كشف لأسماء أو وجود موارد خارج الصلاحية.

## أمثلة أصلية مقترحة

العمود الأوسط أمثلة رسمية للمقارنة، وليست جردًا حرفيًا للنصوص الحالية. يلزم ربطها بالمفاتيح الفعلية بعد اعتماد التصميم.

| السياق | مثال رسمي | المقترح |
| --- | --- | --- |
| لوحة الإدارة | المخرجات التي تتطلب تدخل الإدارة | يحتاج انتباهكم |
| ملخص الحالة | توزيع المخرجات حسب الحالة | وين وصل الشغل؟ |
| قائمة المهام | المهام المسندة إلى المستخدم | مهامك |
| فراغ المهام | لا توجد مهام مسندة إليك | ما عندك مهام مسندة لك حاليًا |
| فراغ المخرجات | لم تتم إضافة مخرجات | ما أضفت مخرجات للحين |
| تفاصيل | فتح مساحة المخرج | عرض التفاصيل |
| فراغ الإشعارات | لا توجد إشعارات جديدة | ما عندك إشعارات جديدة |
| خطأ قراءة الإشعارات | تعذر تحميل الإشعارات | ما قدرنا نحمّل الإشعارات. جرّب مرة ثانية |
| قراءة منفردة | تعليم كمقروء | تحديد كمقروء |
| قراءة جماعية | تعليم الكل كمقروء | تحديد الكل كمقروء |
| رفع ملف | يرجى اختيار ملف للرفع | اختر الملف اللي تبي ترفعه |
| فشل رفع مؤكد | فشلت عملية رفع الملف | ما اكتمل رفع الملف. جرّب مرة ثانية |
| غموض نتيجة حفظ | حدث خطأ | ما قدرنا نتأكد من الحفظ. تحقق من الحالة قبل المحاولة مرة ثانية |
| فراغ الملفات | لا توجد ملفات نهائية متاحة | ما فيه ملفات نهائية متاحة لك حاليًا |
| موافقة العميل | الموافقة على الإصدار المعروض | اعتماد النسخة 3 |
| طلب تعديل | يرجى توضيح التغييرات المطلوبة | وش التعديل المطلوب على النسخة؟ |
| إذن العرض فقط | لا تملك صلاحية تنفيذ هذا الإجراء | حسابك للمشاهدة فقط |
| منع مورد | لا يمكن الوصول للمورد المحدد | ما تقدر تصل لهذا المحتوى |
| دعوة عضو | يرجى إدخال البريد الإلكتروني للمدعو | أدخل بريد الشخص اللي تبي تدعوه |
| إضافة عميل | يرجى تحديد اسم الجهة | وش اسم الشركة أو الجهة؟ |
| حساب الباقة غير متاح | إجمالي المتبقي 0 | ما قدرنا نعرض المتبقي الآن |
| بيانات محفوظة فعلًا | تم حفظ التغييرات بنجاح | تم حفظ التعديل |

تظهر «جرّب مرة ثانية» فقط إن كان المسار يدعم إعادة المحاولة بأمان. لا نعد بحفظ المدخلات أو إمكانية الاسترجاع ما لم يثبت السلوك في الكود والاختبار. نص المستخدم والكابشن والعقود لا تُعاد كتابتها تلقائيًا.

## قاموس لا يتغيّر بين الشاشات

| المصطلح | المعنى |
| --- | --- |
| المخرج | التسليمة المتفق عليها؛ تصميم أو فيديو أو تقرير مثلًا |
| المهمة | خطوة تنفيذية داخل المخرج؛ اكتمالها لا يعني تسليمه |
| العمل / الشغل | تعبير عام في الجملة الإرشادية، لا بديل عشوائي لاسم الكيان |
| النسخة | إصدار محدد يُربط به القرار والملفات |
| اعتماد داخلي | قرار داخلي؛ الإرسال للعميل إجراء منفصل |
| اعتماد النسخة | قرار العميل على النسخة المرسلة، لا نشر أو تسليم نهائي |
| تسليم نهائي | إجراء مستقل بعد استيفاء شروط التسليم |
| المحجوز | الكمية المخصصة للأعمال ولم تُحرر؛ ليست المستهلكة |
| المتاح | وفق الإسقاط الحالي: المتفق عليه + التصحيحات − المحجوز النشط − المستهلك |
| المتبقي | لا يُستخدم لرقم مختلف عن «المتاح» بلا تعريف ظاهر؛ لا تغيير للحساب ضمن دفعة اللغة |
| مدة الانتظار لا تُحتسب على الفريق | توضيح أثر انتظار العميل على SLA، وليس إعلان توقف العمل أو إسقاط الموعد |

معادلة المتاح راجعها القائد في `src/modules/packages/package-ledger.ts`؛ هذه الوثيقة لا تغيّرها.

## اختبار اللغة مع المالك

- هل يمكن تحديد الإجراء التالي خلال 5 ثوان؟ هذا هدف للاختبار وليس نتيجة مُقاسة.
- هل يفهم العميل أن الموافقة على نسخة لا تعني نشرها أو تسليمها؟
- هل «المخرج» مفهوم للفريق والعملاء، أم يحتاج تعريفًا في أول استخدام؟ لا نغيّر اسم الكيان دون هذا القرار.
- هل تبدو النبرة سعودية مهنية دون ألفة زائدة؟
- هل رسائل الرفض والخطأ تعطي خطوة آمنة دون كشف معلومات أو تحميل المستخدم اللوم؟

المصدر اللغوي العام: [صفحة رواء للوحة التحكم](https://rewaa.com/solutions/main-dashboard/) تستخدم نبرة سعودية مباشرة في محتواها التسويقي؛ هذا لا يثبت تفضيلات كل السعوديين أو لغة الواجهة الداخلية كلها. الدليل نتاج مسودة وكيل Astra ومراجعة القائد؛ لم يعمل Flash بسبب رفض تفويض الحمولة الخارجية.
